# 冰系分支兑现与控制记录 · 0.15.19

## 本轮取舍

0.15.18 已让武器参与雷印，但同槽冰环取消叠加后，冰系仍难以兑现。先区分碎冰的短周期伤害与寒牢的储层控制，再通过接触、控制与生存指标判断，不继续统一提高伤害倍率。

炎炮传印次数高，不能直接视为过强：0.15.18 两个保命种子中，雷电来源占总有效伤害约 7.8%/7.0%，环刃则约 9.9%/9.5%。次数与有效伤害并不等价。本轮保留雷系规则，继续观察实际收益。

## 当前规则

- **碎冰两层兑现**：同一敌人被冰环实际接触两次即碎裂，主目标及附近 3 敌各 70% 来源伤害，Lv.5 扩至 5 敌。保持原接触冷却、三秒积层窗口、一秒碎裂锁与每步 16 次预算；未分支的冰霜进化仍需三层。跨槽冲击仍可提前消费冰层。头顶标记同步为两格。
- **寒牢储层换控制**：一层减速 35%，每多一层增加 5 个百分点，五层最高 55%；Boss 仍最高 15%。只在有效冰层和减速状态同时存在时生效；碎裂消费、层数过期后回到基础减速，基础减速结束后恢复正常速度。仍为五层/四秒固定窗口，直伤 ×0.8，不自行碎裂；跨槽冲击和 Lv.5 高层奖励沿用原规则。
- **同槽冰环仍不叠加**：保留旋转相位、接触历史与限频，通过真实接触兑现两层效果。
- **控制诊断**：自动样本增加减速覆盖敌秒、按减速比例加权的敌秒及普通怪/精英/Boss 覆盖。多目标累计值可以超过局内时间；它衡量状态覆盖，不是避免伤害、延迟击杀或真人生存收益。
