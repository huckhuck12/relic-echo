# 0.13.0 首批 Buff 构筑实装

本批完成共同成长底座与火焰冲刺布场。扩展目录仍为后续计划，当前保持 4 种触发、4 种行为、4 种元素和两个配方槽。

## 已完成

- 首次经验升级替换为起始组合选择，最晚由约 20 秒经验补足触发。火焰、冰霜、雷电各装入两条可编辑配方；自由组合保留当前配方，再领取常规强化。后续升级仍为常规强化。
- 等级由完整三片改为按“行为＋元素”共享。同一组合放双槽只升级一次；换触发不丢成长，重开清零。Lv.2 总伤害 +10%、Lv.4 总伤害 +20%，不再通用每级 +20%。
- 火焰区域 Lv.3 弹出独立的分支奖励，二选一，不自动选择。排队期间最多额外升一级，到 Lv.4 后等待选择；多余无匹配碎片转经验。选择与槽号无关，临时换配方也不会把分支发给别的组合。
- 火径：沿实际完成的冲刺起点、中点、终点布置三处火场，各 45% 伤害，持续 3 秒；Lv.5 持续 4 秒。同次施放的重叠区域每个伤害周期只结算一次，仅终点产生火种。剩余容量不足三个时回退为完整基础终点火场；火场总数上限仍为 8。
- 炉心：火场半径 70，伤害 ×1.35；同槽距离 32 内刷新已有炉心。Lv.5 回炉追加一次火场伤害的 60%，每目标锁 2 秒，不再触发元素、标记或其他 Buff。
- 回炉：由另一槽灼烧的存活目标在对应槽的有效火场内，被冲击命中后，向最近火场中心回拉，替换原本向外击退；每目标锁 1 秒。Boss 不强制移动，精英继续经过既有抗性与移动碰撞处理。
- 冲刺 Buff 冷却改为 1 秒，仍在冲刺结束触发；编辑、选分支不重置冷却。场上效果保留释放时的等级、分支、槽位、施放编号和伤害快照。
- 地面碎片候选保留未解锁项，并给予当前可升级配方双份权重；首精英选卡优先给当前可升级项。自动试玩能领取新奖励；浮动摇杆把起始组合与分支视为可接续的奖励弹窗。

## 验证

- `npm test`：250 项通过，含新增 8 项构筑规则/流程测试。覆盖同次火径去重、容量回退、伤害快照、成长共享、分支互斥、回拉锁及恢复、Boss 免拉、死亡目标不反应、旧卡片身份失效和各屏幕卡片尺寸。
- `npm run format:check` 通过；`npm run build:wechat` 生成 0.13.0，包体 3,917,712 字节，低于 4 MiB。
- H5 393×852、852×393、1280×720 使用真实 Laya/WebGL，实际触摸/鼠标点击起始卡与分支卡通过，无脚本异常。截图已检查横屏起始组合与微信模拟竖屏分支页。
- 微信 SDK 浏览器模拟检查通过：手指 7 持续按住浮动摇杆，第二指领取起始组合与成长分支后仍保留原手指与移动方向；治疗、装备等旧奖励及失焦行为继续回归。
- 冻结绘制回归与微信固定压力场景通过，后者为 235 怪、208 弹、150 掉落，28 DC。详细数据见 [验证数据](buff-build-results-0130.json)。此固定场景用于旧绘制路径回归，不代表火径、火种、回炉同时活跃的增量成本已经完成真机验收。
