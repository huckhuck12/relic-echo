# 元素特效制作记录 · 0.12.3

沿用 B「遗迹学徒」手绘幻想方向：火焰为琥珀暖芯，冰霜为浅蓝碎晶，雷电为淡紫分枝，冲击为赭金气流。

原始图由用户授权的图像生成流程制作，以 `output/imagegen/hero-b-ruin-apprentice-v2.png` 为参考。提示词为 `output/imagegen/element-vfx-prompt.txt`，实际源图为 1280×1280 的 `element-vfx-source.png`。`scripts/build-vfx-art.ps1` 和 `VfxAtlasBuilder.cs` 清除色键残留及孤立噪点，按四元素 × 弹体/命中/区域/核心排列，归一化到 `assets/vfx/elements.png`（512×512，16 格）。资产检查记录在 `elements.json`，色键残留为零。

运行时所有画质共享一张 1 MiB RGBA 图集；加载失败保留程序绘制。地面和上层素材分别集中绘制，范围边界继续用矢量表示，地面效果在角色下方。不会为每只怪物创建纹理、滤镜或计时器。

本批覆盖三武器的释放/命中/持续效果、四行为 × 四元素的 16 种 Buff、灼烧和减速状态，以及雷印引爆、火种连线、冰层碎裂三进化。火球弹体重新设计轮廓但仍烘焙进原有共享实体图集，避免大量飞弹产生纹理切换。伤害数值、范围、碰撞、触发时序和随机序列不变。

`bench/vfx-review.html` 为真实 Laya WebGL 样张；`scripts/vfx-audit.mjs` 检查三个画质和等级、短时爆发与持续效果，以及共享内存和绘制批次。新增单元测试验证上传/失败回退、16 组合、分层、进化淡出和素材结构。

本批不包含怪物整体重画。iPhone Air 真机长时间稳定性和实机帧率仍需复测，桌面浏览器结果不能证明微信整进程闪退已解决。
