# 后续视觉制作清单

方向：沿用已选 B「遗迹学徒」的手绘幻想风格。以下是待制作和验收范围，不表示资源已经完成。当前落地版本 0.15.14；以下历史版本记录保留各自验收边界。

0.15.14 为地图玩法提供对应信息：清剿边界/交叉符、三点巡回路线与当前驻留条、指定守卫冠标，以及 HUD 真实目标/方向/剩余时间。巡回三点布置避开左侧伤害排行与底部摇杆，不新增纹理或碰撞。地图事件与怪潮规则、样张和人工验收边界见[制作记录](../map-encounters-01514.md)；本轮沿用区域美术，未重画场景。

0.15.13 区分敌方弹道：法师细针、精英晶锤、Boss 分叉冠刃；释放标记呼应来源，节点短回弹与末段轻退亮度。复用原 341 格/8 MiB 敌人图集，不新增粒子实体；356 项测试通过，微信固定场景仍为 28 DC。见[样张与边界](enemy-projectiles-01513.md)。本轮未增加 Boss 弹幕种类，未重画新的位图源；受击消散材质、真机密集可读性及地图事件差异继续验收。

0.15.12 深化 Buff 状态与联动：雷印/冰层分排、脚下减速/侧边灼烧、炉心纹路、回炉内收/碎冰外射/传印方向和单体蓄雷亮芯。复用现有素材，354 项测试通过，见[制作记录](buff-vfx-01512.md)。未新增冻结玩法，任意配方材质、敌方弹道与真机可读性继续验收。

0.15.10 增加弹窗短淡入/上浮/收拢及自动试玩设置入口，见[实现](../thunder-autoplay-01510.md)。敌方子弹仍是程序造型生成的共享图集；下一批需深化敌我弹道、粒子材质与分区事件玩法，本轮未重画这些资源。

制作顺序：玩家挂载/动作与性能基础 → 三武器与 16 种 Buff 组合 → 三进化及状态反馈 → 三普通怪 → 精英/Boss → 场景与 UI 细化。每一批先做同屏样张，再接入共享图集并比较实测 DC、纹理内存和视觉可读性。

资源约束：继续共享纹理、按离散姿态更新图形命令；不要把所有完整动作帧、装备组合展开成独立大图。需要新增内存时先计算并实测预算。完成桌面真实 WebGL、微信打包和触控回归后，仍需 iPhone Air 真机长时间测试；浏览器结果不能关闭整进程闪退问题。
