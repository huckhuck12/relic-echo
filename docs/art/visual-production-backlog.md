# 后续视觉制作清单

| 范围 | 需要覆盖的内容 | 验收重点 |
|---|---|---|
| 玩家 | 八向待机、左右脚交替行走、站立施法、移动攻击、受击、冲刺；头饰、护甲与背饰 | 武器握把与手部相连；脚底和阴影稳定；移动攻击不中断步态。原行走源仍需更清楚的左右脚交替，不能把重新定时当成动作重绘完成。 |
| 三种武器 | 雷杖：释放、连锁与落点；炎炮：枪口、弹丸、命中、燃烧区域；环刃：腕部引导、绕行、释放与收回 | 共用挂点；特效起点跟随当前姿态；画面范围与真实伤害范围一致。0.12.2 已接入三种手绘武器挂件，0.12.3 已统一释放、命中和持续效果。 |
| Buff 行为 | 弹丸 bolt、爆炸 blast、区域 field、环绕 orbit | 0.12.3 已覆盖每种行为与四种元素组合，共 16 种；改变轮廓和节奏，不能只换颜色。 |
| Buff 元素 | 火焰、冰霜、雷电、冲击 | 火焰用琥珀暖芯与烟边；冰霜用浅蓝晶片；雷电用淡紫细枝；冲击用暖白尘环。始终保留危险范围和命中可读性。 |

| 普通怪 | 苔芽史莱姆、遗迹法师、荒野野猪 | 保留种类轮廓，重绘柔和材质、转向和攻击关键帧；法师的法杖、手部、弹道挂点共用动作变换。 |

| 场景与 UI | 草地/遗迹路径、石柱、掉落；HUD、卡片、背包、性能面板与图标 | 与角色统一材质和线条；小屏正文可读、摇杆区无拦截；危险信息优先于装饰。 |

制作顺序：玩家挂载/动作与性能基础 → 三武器与 16 种 Buff 组合 → 三进化及状态反馈 → 三普通怪 → 精英/Boss → 场景与 UI 细化。每一批先做同屏样张，再接入共享图集并比较实测 DC、纹理内存和视觉可读性。

资源约束：继续共享纹理、按离散姿态更新图形命令；不要把所有完整动作帧、装备组合展开成独立大图。需要新增内存时先计算并实测预算。完成桌面真实 WebGL、微信打包和触控回归后，仍需 iPhone Air 真机长时间测试；浏览器结果不能关闭整进程闪退问题。

0.12.3 已完成三武器技能、16 种 Buff、灼烧/减速与三进化的手绘元素素材接入，详见[制作记录](element-vfx-production.md)。浏览器与微信打包验收完成后仍需真机复测。怪物整体重画、玩家更清晰的步态源图、场景/UI 深化尚未完成。
