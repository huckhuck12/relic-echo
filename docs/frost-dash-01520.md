# 冲刺收割冰层 · 0.15.20

## 操作与结算

冰环半径 150，而冲刺落点冲击半径 110。旧规则下，穿过已冻目标可能使目标落在落点爆炸外，玩家做出正确方向操作仍无法碎冰。本轮让跨槽 `dash/blast/force` 收割实际经过的冰层。

- 按真实移动分段记录路径，路径半径 56；路径和落点合计最多 8 个目标。绕障碍不会按起终点直线抄近路。
- 冲刺结束后，在普通落点冲击之前消费冰层，避免普通冲击先杀死目标。沿途不增加普通冲击伤害。
- 必须有仍有效、未锁定、来自另一槽的冰层；结算时重新校验生死、过期、锁定与来源。伤害使用原冰层来源快照，归入冰系来源排行。
- 保留原分支倍率、高层奖励、一秒碎裂锁及每步 16 次反应预算；一次冲刺中的同一目标只消费一次。未通过的目标不延期补结算；离场清理路径和待处理记录。
- 冲刺就绪且附近存在可消费目标时提示“穿冰冲刺可碎裂”；四层及以上提示“高层冰 · 冲刺碎裂”。冰层标记增加就绪框，成功时短暂显示落点至目标的收割切线。沿用现有反馈预算与操作按钮。
