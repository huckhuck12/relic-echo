# Buff 实战收益首轮调整 · 0.15.15

## 改动

- Lv.2/4 的伤害成长由每档 +10% 改为 +35%，Lv.1–5 倍率为 1 / 1.35 / 1.35 / 1.7 / 1.7；Lv.3/5 继续承载分支机制。描述与实战共用成长公式，已释放效果保留旧快照。
- 火径每个火场由 45% 改为 85% 基础伤害。同次冲刺的重叠仍不叠伤，持续时间、火场数与上限保持原规则；补偿铺路分散后单个目标只能吃到一份伤害的问题。
- 环绕基础伤害 12 → 20，保留真实双轨道接触和单目标接触冷却，不把整块圆盘变成伤害区域。
- 雷弹追踪目标死亡后，在当前位置 500 范围内仅重新寻找一次最近存活目标。保持转向速度、弹速、碰撞、寿命与数量上限；不逐帧全场索敌，不引入随机调用。
- 诊断脚本新增分阶段有效伤害、每种行为/元素的释放次数、至少命中一次的释放数和接触次数；火径三片共用一次释放计数。

## 尚未解决

远程武器常在敌人进入冰环前将其击杀；单纯提高接触伤害无法解决接敌不足。雷印仍受到目标提前死亡、分散叠层与触发冷却制约，保命雷杖雷系的全局占比甚至下降。下一轮应分别校准冰环接触机会、雷印积累与分支兑现，继续测普通存活和 Boss，不用无限叠倍率代替机制调整。

控制类 Buff 还需要减速覆盖、危险攻击规避等效用指标，伤害占比不能完整代表它们的价值。本轮没有完成全部表现制作，也没有新增 iPhone 真机性能或手感结论。
