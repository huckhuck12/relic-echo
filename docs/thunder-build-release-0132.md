# 0.13.2 雷电构筑实装

三套首批构筑的机制已齐备。本次补齐导冷、传印与蓄雷，不增加碎片、配方槽或图片资源；仍为 4 触发 × 4 行为 × 4 元素。8×8×6 目录与改造位仍是后续设计。

## 战斗规则

- 导冷：目标受另一槽冰霜 Buff 直接施加的有效减速时，雷电弹丸直击额外加一印，每目标一秒一次。一发最多两印，只检查一次分支阈值。普通武器减速、碎裂扩散减速、同槽及无槽来源均不满足条件。
- 两槽冰霜来源分别计时，不因后续同槽命中覆盖，也不被无来源扩散减速续期。效果清理、死亡与重开沿用原生命周期。
- 未选分支沿用九秒三印、主目标 160% 与附近最多三敌各 80% 的引爆。
- 传印：主目标引爆 120%，向半径 180 内最多三名其他存活敌人传一印，Lv.5 为五名；取消旧引爆溅射。传播不能引爆，最多叠至邻居已有分支阈值前一层，保留其分支与首次计时，跳过锁定目标。
- 蓄雷：五印引爆主目标 300%，Lv.5 为 350%；没有引爆溅射。基础雷电元素自身的最多两敌 55% 传导保留，其伤害不能叠印。
- 雷印从首层起九秒失效，后续接触与传印不刷新；引爆先清层、设一秒锁再发伤害，锁内不叠层。基础命中致死不追加尸体反应。
- 雷印表上限 200 目标，每逻辑步最多 16 次雷爆；预算不足不消费原层数、不预留导冷或引爆锁。没有延迟引爆队列，后续接触可重试，原窗口仍到期。拒绝计数为 `thunderRejected`。

## 成长与呈现

- 雷电弹丸 Lv.3 二选一，沿用配对身份、独立排队和奖励令牌；火焰/冰霜选项不能误领给雷电。换触发保留成长，新分支只作用于之后释放的弹丸。
- 起始卡说明导冷；分支卡与编辑面板读取同一目录，矮横屏用简版。蓄雷五格、其他雷印三格；爆发锁定期间显示短计时线，仍受原有共享可见标记预算限制。
- 复用元素图集和反馈池，不增加图集页、传播队列或显示节点。
