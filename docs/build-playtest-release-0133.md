# 0.13.3 构筑试玩与接触修正

本轮补齐可重复的整局验证，并修正持续效果把自己的目标推出范围的问题。没有修改伤害倍率、碎片掉率、升级门槛或敌人血量。三构筑的整局平衡尚未完成。

## 游戏变化

- 火场和环绕的基础持续接触不再附带普通命中的物理击退；元素伤害、灼烧/减速/积层和元素反馈保留。冲击元素仍按原规则推移，回炉仍拉向火场；弹丸、爆炸和进化爆发的击退保留。
- 自动试玩按火径、炉心、碎冰、寒牢、传印、蓄雷轮换；每条路线连续测试三把武器，18 局为一轮。测试中只接受当前武器的同类升级，防止途中换武器污染对比。没有达到 Lv.3 的失败局不会强行解锁分支。
- 根据当前实际配方，冰环尝试接近接触距离，跨槽冲击寻找至少两层的冰层目标，冲刺布场寻找附近敌人。紧急避让优先；主动连招检查 Buff 冷却、边界、落点柱子、预测弹道和 Boss 已知圆形预警。仍是启发式 AI，不能覆盖所有危险或等同真人操作。
- 普通试玩正常死亡，保命压测维持原有致命伤留一血；不自动复活、不提交战绩，后台或手动暂停时停止。
- 暂停面板显示当前计划路线；复制诊断中同时保留计划路线和实际装配/等级/分支，避免将计划当作已经成型。结果保留最近 18 局，动作保留 24 条。

## 固定种子整局对比

运行 npm run check:balance -- --seeds=627 --weapons=storm,flame,blade --out=artifacts/build-after.json，附加 --legacy-contact 可在测试脚本中恢复旧持续接触击退，其他 AI 与规则相同。附加 --normal 则关闭保命。默认测试两个种子与雷杖，完整原始事件/每分钟检查点输出到 artifacts。

完成旧规则 18 局、新规则 18 局，另有新规则雷杖六分支普通试玩 6 局。记录见[精简结果](data/build-playtest-0133.json)。伤害在实际扣血钩子中封顶过量伤害，排除命中回调嵌套的重复统计；反应直接在接纳爆发时计数，不受 Boss 清场归零影响。

## 结果的含义与下一步

- 持续接触不应把目标自动推出去，这是独立的机制冲突，已有真实 Game 伤害入口测试。整局伤害并非每条路线都上升，不能声称一次修正就让三构筑平衡。
- 六个冰霜样本合计仅 3 次碎裂，六个雷电样本合计 7 次雷爆。冰环接触/积层的兑现、雷丸持续命中同一存活目标和 AI 操作仍需专项定位。优先区分碰撞采样、武器击退/抢杀、目标选择和决策空窗，再改阈值或数值。
- 18 局保命样本全部覆盖 Boss 阶段，只说明流程可达，不是生存率。六条雷杖普通样本在 231.3–313.6 秒结束；失败、超时与胜利保留原样，不为完成覆盖改写结果。真人仍需比较近身风险、转火损失和两个分支的操作差异。
- 固定种子不代表每局相同敌群：不同命中/击杀会消耗不同随机序列。这里只用于复现整条路线，不能据单种子宣称因果或统计显著。
- Node 使用图形桩，不包含 WebGL/GPU/原生帧率；iPhone Air 热机、触控和微信整进程退出仍待真机验收。
