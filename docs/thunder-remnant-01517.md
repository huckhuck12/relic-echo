# 雷印击杀余电 · 0.15.17

## 规则与边界

雷丸直接击杀普通怪或精英，或带有有效雷印的目标被其他伤害击杀后，向 180 范围内最近一个符合条件的存活敌人继承印记。每印造成来源快照伤害的 40% 放电；传印/默认最多继承两印，蓄雷最多四印。致死雷丸会把本次新投入的印记与既有雷印合并，只结算一次。

继承不会直接引爆，最多把接收者叠到其自身分支阈值减一；需要后续雷丸直击才能引爆。保留接收者既有来源与剩余窗口，新继承窗口不超过死者剩余时间；不刷新九秒窗口、不绕过爆发锁。已有继承能量的目标不会连续吸收余电。

继承标记不能因死亡再次传播。只有新雷丸直击投入后，才重新获得一次死亡继承资格。先保留继承状态、再放电；即使放电击杀接收者，也不会形成递归爆炸。Boss 死亡不触发余电。

每个模拟步最多 16 次继承搜索（未找到目标也扣预算），目标雷印沿用 200 上限；无延迟死亡队列、无新增随机调用。死亡奖励按原顺序完成后再处理既有雷印，致死基础雷丸的死亡回调暂缓处理自身印记，回到唯一 Buff 接触入口后合并结算。余电伤害归属雷电弹丸，走实际扣血排行，不计算溢出伤害；放电不派发 hit/kill Buff。

复用现有弧线反馈队列和预算，无新图集。完整配方和紧凑分支说明均展示击杀继承。

## 逻辑样本

三武器 × 传印/蓄雷 × 种子 1104/627 × 普通/保命，共 24 局。1104 与 0.15.16 配对，627 仅为额外验证，没有改前配对样本。真实奖励、有效扣血、相同自动操作策略；战斗改变后随机序列会分叉，单种子差异不能当成显著性或真人胜率。

种子 1104 普通样本，雷电弹丸来源全局有效伤害：

| 武器 | 传印 | 蓄雷 |
|---|---|---|
| 雷杖 | 3,685 → 5,460 | 3,685 → 4,352 |
| 炎炮 | 9,318 → 12,059 | 9,318 → 11,422 |
| 环刃 | 7,374 → 8,903 | 7,374 → 9,802 |

不同存活时间意味着这不是单位时间伤害对比。普通 12 局每局发生 47–115 次继承，保命每局 66–156 次，击杀投入能够在清怪阶段产生实伤，不再只能等 Boss 积累。

保命 12/12 完成 Boss；普通 1/12 通关（种子 627 炎炮蓄雷 612 秒）。配对的 1104 普通六局均未通关；雷杖传印存活 505.9 → 524.9 秒，雷杖蓄雷 505.9 → 503.9 秒，炎炮传印 565.4 → 532.0 秒，炎炮蓄雷 565.4 → 486.9 秒，环刃传印 499.3 → 459.5 秒，环刃蓄雷 499.3 → 445.8 秒。

配对保命雷杖两分支的总 Buff 占比下降（传印 7.6 → 6.1%，蓄雷 7.6 → 5.6%）；配对普通环刃蓄雷 17.1 → 22.0%。保留这些退步结果，不宣称整体难度或所有构筑都改善。

原有叠印引爆仍稀少：普通 12 局只有一局有一次引爆，其余为零。余电收益与真正引爆分别统计，不把继承次数当成引爆次数。下一步仍要评估分支阈值、怪物血量与武器抢杀之间的关系，同时补充真人手感和多种子平衡校准。
