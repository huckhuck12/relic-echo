# 0.14.3 自动试玩导航修正

本轮使用 game-ai skill 拆分目标取舍和局部避险，只调整自动试玩。武器数值、怪物难度、掉落与普通玩家操作保持原规则。

## 修正内容

- 飞刃基础射程只有 150，原控制器却沿用 220 的远程绕行距离。现在读取实际武器射程及飞刃范围升级，以射程的 75% 为目标、最多保持 220 距离；冰环仍优先 105 的接触带，短程减少普通怪的排斥距离。
- 紧急冲刺原先只要危险就发动。现在优先检查撤离朝向，最多尝试五个方向，检测沿途柱子、冲刺期间的相对弹道、地图边缘和落点怪物/蓄力/Boss 预警；全部不安全则继续走位、不消耗冲刺。允许从已经重叠且持续远离的弹道中撤出。这是有限前瞻，并非完整寻路或安全保证。
- 封印接取要求至少 55% 生命，已启动时降至 30%；按移速估算路程并留 3 秒余量，已启动时计入剩余守护时间；附近普通怪/精英过密或存在冲锋/Boss 时先避险。可用事件只要求能在显现期限内启动，启动后使用独立的 45 秒挑战时限。
- 寻找治疗掉落的加权判断改为低于最大生命的 70%，不再用固定 70 点生命。
- 每 150ms 决策一次，最多五次线性危险检查；不新增逐帧寻路、渲染节点、贴图或额外模拟帧。普通试玩仍正常死亡，保护压测仍明确区分。

## 普通逻辑对照

沿用 0.14.2 的种子 627 / 1104、三武器和六分支，共 36 局，无死亡保护；使用真实移动、攻击、奖励和事件流程。数据见 [0.14.3 原始样本](data/auto-navigation-normal-0143.json)，基线为 [0.14.2 样本](data/standard-pressure-normal-0142.json)。

| 样本 | 0.14.2 平均存活秒数 | 0.14.3 平均存活秒数 |
| --- | ---: | ---: |
| 雷电 12 局 | 506 | 546 |
| 火焰 12 局 | 471 | 495 |
| 飞刃 12 局 | 367 | 408 |
| 全部 36 局 | 448 | 483 |

到达 Boss 从 0/36 变为 3/36，全部是雷电；两版均无通关。新样本范围 273.93–628.37 秒，完成封印从 85 减至 76。逐一匹配种子、武器和分支，23 局存活延长，13 局缩短；并非每种构筑都改善。低血量离开目标可能失去奖励；方向与击杀变化也会改变后续随机数消耗，不是完全相同遭遇的重放。

以上为 Node 逻辑样本，不能代替真人难度、真机帧率、GPU 或触控测试。飞刃与火焰仍未到达 Boss，后续应结合人工长局观察，再决定是否调整成长或怪物曲线，不能仅以自动通关为目标放宽难度。
