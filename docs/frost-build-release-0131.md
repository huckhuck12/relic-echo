# 0.13.1 冰霜构筑实装

本批增加冰霜跨槽碎裂和两条成长分支，继续复用两个自由组合槽。雷电的导冷、传印和蓄雷尚未实装。

## 战斗规则

- 未选分支时，冰环保留原有三层自动碎裂；现在另一槽的冲击也能提前消耗至少两层冰层。主目标每层受到冰环伤害快照的 40%，半径 90 内最多四个其他目标各受 40%。
- 碎冰：自然三层碎裂替换为对半径 110 内最多三个其他目标各造成 70% 伤害，不再重复施加旧版范围碎裂伤害；Lv.5 最多五个目标。孤立目标没有额外冰片伤害，仍可用跨槽冲击提前引爆。
- 寒牢：冰环直接伤害 ×0.8，但反应保留未削弱的基础伤害快照；从首层开始计时四秒，最多五层，不刷新窗口、不自动碎裂。跨槽冲击消耗冰层；Lv.5 消费至少四层时，主目标碎裂伤害再 ×1.25。
- 冰层来源记录槽位、分支、等级和伤害；同槽冲击、无来源冲击、一层、超时和死亡目标都不能消费。消费先清层并设一秒锁，再发伤害，额外伤害不回到普通 Buff 命中入口，也不传播冰层。
- 冰层保持有界表，最多 200 个目标；每逻辑步最多 16 次冰霜爆发。预算不足时不消费冰层、不加锁，后续有效接触可以重试；没有自动延迟引爆队列，原有窗口仍会到期。`frostRejected` 记录拒绝次数。
- Boss 的 Buff 减速从 35% 降为最多 15%，保留冰层与碎裂伤害；普通怪继续减速 35%。蓄力、预警、攻击计时和打断规则未改。

## 成长与界面

- 分支目录独立为数据。火焰区域与冰霜环绕分别按配对身份请求奖励，换触发/换槽仍保留成长，不能把火焰的选项领给冰霜。
- 冰环 Lv.3 二选一；排队期间最多继续到 Lv.4，选完后才能到 Lv.5。新分支只影响之后释放的效果，场上的旧效果保留原快照。
- 寒牢标记显示最多五个小刻度，仍受原有可见标记预算限制；冰片命中使用已有冰霜素材与反馈预算，不新建独立图集。
- 选卡说明和 Buff 编辑页读取共同的分支文案。矮横屏显示简版说明，避免完整说明过长被隐藏；伤害数字保留一位小数。
- 自动试玩沿用通用奖励领取；微信模拟中的第二指领取冰霜分支后，第一指仍持有浮动摇杆并保留移动方向。
